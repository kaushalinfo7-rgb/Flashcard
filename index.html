JSON format reference

Keep every card focused on one fact, concept or association.

[
  {
    "front": "What is the main question or term?",
    "back": "A concise, accurate answer.",
    "explanation": "Optional short clarification.",
    "tags": ["definition", "prelims"],
    "source": "Syllabus / book / page reference"
  }
]

Required fields: front and back. Alternatives accepted: question/answer, term/definition, or prompt/response. Optional data like explanation, tags and source are kept when provided.
